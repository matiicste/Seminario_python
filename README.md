Instalation

1. Open Powershell/Bash/Terminal and navigate to project folder.
2. Run python -m venv .venv for creating venv.
3. Run .venv/Scripts/activate for activating venv on Windows.
4. Run pip install -r requirements.txt for installing libraries from requirements file.
5. Run fastapi run for running app at localhost and default port (8000).
6. Open browser and go to localhost:8000/docs for swagger documenta
